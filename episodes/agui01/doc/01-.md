# 三协议关系（AG-UI / MCP / A2A）

> 信息源
> - 官方: https://docs.ag-ui.com/agentic-protocols
> - 本地原文: `~/projects/_agui-docs-readings/ag-ui/docs/agentic-protocols.mdx`

## 三协议定位

Agentic 生态围绕一族开放、互补的协议组织起来，每个协议覆盖一层不同的交互[^layers]：

| 协议 | 全称 | 连接对象 |
|---|---|---|
| **MCP** | Model Context Protocol | agent ↔ 工具 / 上下文 |
| **A2A** | Agent to Agent | agent ↔ agent |
| **AG-UI** | Agent–User Interaction | agent ↔ 用户（通过面向用户的应用） |

AG-UI 自我定位为 "kitchen sink" 协议——由自下而上的、构建一流 agentic 应用的真实需求驱动而成[^kitchen-sink]。

## 三协议互补，可同时使用

> These three agentic protocols are complementary and have distinct technical goals; a single agent can and often does use all 3 simultaneously.[^complementary]

```
                  ┌──────────────┐
                  │   前端 App    │
                  └──────┬───────┘
                         │ AG-UI （向用户）
                         ▼
                  ┌──────────────┐
         A2A ◀───▶│    Agent     │◀──▶ MCP（调工具/数据）
   (跨 agent 协作) └──────────────┘
```

## AG-UI 与 MCP / A2A 的 handshake

AG-UI 贡献者近期加入了 handshake 机制，让 AG-UI 可以为 MCP 与 A2A 协议的 agent "front for"（代言），使 AG-UI 客户端应用与库能无缝使用 MCP / A2A 支持的 agent[^handshakes]。

AG-UI 的使命是支持现代 agentic 应用所需的全部 building blocks[^mandate]。

## Generative UI Specs 生态

近期发布了若干 generative UI 规范，允许 agent 通过交互协议投递 UI widget。AG-UI 与它们全部兼容[^genui-specs]。

| 规范 | 说明 |
|---|---|
| **MCP-UI** | 基于 MCP 的 UI widget 规范 |
| **Open JSON UI** | 通用 UI 描述 JSON schema |
| **A2UI** | 基于 A2A 的 UI widget 规范 |

## QA

### Q1: "kitchen sink" 协议意味着什么？

AG-UI 不追求理论上最干净的抽象，而是覆盖真实 agentic 应用需要的全部交互场景。它的 building blocks（流式、多模态、generative UI、shared state、HITL、sub-agent……）是从应用侧需求倒推出来的，因此看起来庞杂。对照之下 MCP 只管工具接入、A2A 只管 agent 协作，AG-UI 承担的面最宽。

### Q2: handshake 在工程上意味着什么？

若后端 agent 已经是 MCP 或 A2A 实现，不需要重写为 AG-UI 原生——通过 handshake，AG-UI 客户端库可以把这些 agent 包装成 AG-UI 事件流，前端按 AG-UI 统一消费。这是生态位扩张策略：前端层用一套 AG-UI 客户端通吃三种后端。

### Q3: A2UI 和 AG-UI 容易混淆吗？

容易。两者职责不同：

- **AG-UI**：事件流传输协议（agent → 用户）
- **A2UI**：UI widget 描述格式（在 A2A 传输上投递 UI）

AG-UI 负责"怎么传"，generative UI specs 负责"传什么形状的 UI"，两者正交。

### Q4: 一个 agent 同时用三协议的画面？

- 对**用户**：AG-UI（事件流驱动前端 UI）
- 对**工具 / 数据源**：MCP
- 对**其它 agent**：A2A

三条线正交，互不干扰。
